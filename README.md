Inicializar git - git init

Criar pasta - mkdir nome_pasta

Entrar na pasta - cd nome_pasta

Criar arquivo -  touch nome_arquivo

Crair uma branch - git branch -m nome_branch

Alterar o arquivo - Mexer no arquivo do vscode

Commitar - git commit -m "Mensagem"

Criar um repositório - git remote add origin URL_do repositorio

Enviar arquivo para o repositório - git push -u origin main

Mesclar branchs -  git merge main
